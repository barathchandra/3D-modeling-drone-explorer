# Flydronics — Premium 3D Drone Experience

Next.js 15 showcase site with React Three Fiber, GSAP ScrollTrigger, Lenis smooth scroll, and an exploded-view scroll narrative.

## Stack

3d compnenet view application

- Next.js 15, React 19, TypeScript
- React Three Fiber, Drei, Three.js, Postprocessing
- GSAP ScrollTrigger, Framer Motion, Lenis
- Tailwind CSS

## Assets

- `public/models/drone.glb` — primary 3D model (from `textured_mesh.glb`)
- `public/images/drone-reference.png` — product reference image
-
